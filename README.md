# z0rd0nlander

One Claude Code marketplace for every plugin, skill and agent by z0rd0n88. Each plugin keeps its own repo; this one only points at them.

```
/plugin marketplace add z0rd0n88/z0rd0nlander
/plugin install think-time@z0rd0nlander
```

Some source repos are private, so only people with access to them can install those plugins, and claude.ai cannot sync them: it reports "Repository not found" for a plugin whose source repo it cannot read.

Plugin names are lowercase letters, numbers and hyphens only, and a plugin must not have a top-level `bin/` directory. claude.ai rejects a plugin that breaks either rule.
